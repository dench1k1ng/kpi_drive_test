# KPI-DRIVE Канбан-доска

Тестовое задание: Flutter приложение для управления задачами в стиле Trello с интеграцией KPI-DRIVE API.

## 🎯 Выполненные требования

### ✅ Функциональность
- **Канбан-доска** с drag-and-drop между колонками
- **API интеграция** с KPI-DRIVE сервером (GET/POST)
- **Защита от дурака** - откат изменений при ошибке API
- **Красивый UI** в стиле KPI-DRIVE (темная тема, цветные индикаторы)
- **Интуитивный интерфейс** - минимум кликов

### 🛠 Технологии
- **Flutter** + **Dart**
- **MVVM архитектура** с Provider
- **HTTP** для API запросов (multipart/form-data)
- **kanban_board** пакет для drag-and-drop
- **Bearer Token** авторизация

### 📋 API endpoints
1. **GET задачи**: `POST /indicators/get_mo_indicators`
2. **Сохранение**: `POST /indicators/save_indicator_instance_field`

### 🎨 UI особенности
- **Темная тема** в стиле KPI-DRIVE
- **Цветные KPI индикаторы** (синий, зеленый, желтый, красный)
- **Sidebar** с KPI метриками
- **Карточки задач** с прогресс-барами
- **Уведомления об ошибках**

### 📱 Структура колонок
- **К выполнению** - новые задачи
- **В работе** - задачи в процессе
- **На проверке** - задачи на ревью
- **Выполнено** - завершенные задачи

### 🔒 Защита от дурака
- Автоматический откат при ошибке API
- Валидация перед отправкой
- Показ демо-данных при недоступности API
- Уведомления пользователю

## 🚀 Запуск
```bash
flutter pub get
flutter run
```

## 📹 Демо
Приложение готово для записи демо-видео с полным функционалом drag-and-drop и API интеграцией.
